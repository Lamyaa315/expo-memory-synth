# Expo Memory Synth

تجربة تشاركية للزائر اللي ما يقدر يسافر للرياض: زائر في الموقع يصور الجناح بجواله، ونبني منه مشهد ثلاثي الأبعاد (Gaussian Splatting) مع سرد ثقافي وصوت محيطي، يفتحه أي شخص بعيد من رابط.

**المسار:** الإرث الثقافي والترويج، تحدي 6.5 (الزائر الذي لا يستطيع السفر إلى الرياض)

## كيف يشتغل

```
فيديو من الجوال
   ↓  scripts/extract_frames.py
فريمات
   ↓  scripts/blur_faces.py        (خصوصية: طمس الوجيه)
   ↓  COLMAP                        (مكان الكاميرا لكل صورة)
   ↓  gsplat                        (بناء المشهد 3D)
scene.ply
   ↓  scripts/narrate.py            (LLM يكتب السرد + وصف الصوت)
   ↓  scripts/make_audio.py         (تحويل السرد لصوت)
web/  ←  الزائر البعيد يفتح الرابط
```

| `scripts/clean_scene.py` | ينظف المشهد من النقاط الطايرة ويسوي نسخة خفيفة `.splat` |

## البداية السريعة

### 1. بناء المشهد (Colab أو Kaggle)
التدريب يحتاج كرت شاشة NVIDIA، فيشتغل على السحابة:
- **Colab:** افتحوا `notebooks/01_reconstruction_colab.ipynb` من GitHub مباشرة (`File > Open notebook > GitHub`)، واختاروا **T4 GPU** من `Runtime > Change runtime type`.
- **Kaggle** (حصة GPU مجانية أكبر كل أسبوع): `Create > New Notebook > File > Import Notebook` وارفعوا الملف. من `Settings` اختاروا **GPU T4 x2** وشغلوا **Internet**.

بالخلية 2 عبوا `VIDEO_NAME` و `FILE_ID` (رقم الفيديو من رابط Drive المشارك) و `SCENE_NAME`. شغلوا الخلايا وحدة وحدة. النوتبوك يضبط عدد الصور تلقائياً حسب طول الفيديو (`TARGET_FRAMES`)، ويشغل loop detection للفيديوهات الطويلة.

**نصايح التصوير:** امشوا حول القطعة ببطء (orbit)، 20-60 ثانية، لقطة وحدة بدون قص، إضاءة ثابتة، وبدون ناس يتحركون قدام الكاميرا.

### 2. تنظيف المشهد
حطوا الملف في `web/scene.ply`، وبعدين نظفوه بطريقة من ثنتين:
- **تلقائي:** يشيل النقاط الطايرة البعيدة عن القطعة، ويسوي نسخة خفيفة `web/scene.splat` (أصغر 7 مرات تقريباً) يحملها الموقع أول:
  ```bash
  python scripts/clean_scene.py web/scene.ply --center X Y Z --radius 1.3 --min-opacity 0.01 --splat
  ```
  `--center` مكان القطعة بالمشهد (تقدرون تعرفونه من وضع التحرير: حطوا نقطة على القطعة وشوفوا `position` بـ hotspots.json). الأصل ينحفظ باسم `scene_full.ply`، فتقدرون تعيدون بقيم ثانية.
  لا ترفعون `--min-opacity` كثير: بعض القطع مبنية من نقاط شفافة فوق بعض وتختفي.
- **يدوي:** افتحوا الملف في [SuperSplat](https://superspl.at/editor)، قصوا الأطراف المشوهة، وصدروه.

  - **Crop box:** إذا فيه نقاط مشوشة بين الكاميرا والقطعة، احذفوا الشريط هذا: مثلاً `--min any -0.9 any` يحذف كل شي `y` حقه أقل من -0.9.

### جولة على مسار التصوير (للأجنحة والممرات)
المشهد يطلع واضح **من الأماكن اللي مشت فيها الكاميرا** بس، ويتغبش لما تبعدون عنها. عشان كذا الزائر "يمشي" على نفس مساركم:
1. نزلوا من الـ Drive مجلد `outputs/<SCENE_NAME>/sparse/0` (فيه `cameras.bin` و `images.bin` و `points3D.bin`) وحطوه بـ `data/<SCENE_NAME>/sparse`.
2. سووا الجولة:
   ```bash
   python scripts/camera_path.py data/hall/sparse --stops 15
   ```
   يطلع `web/tour.json`، والموقع يعرض شريط "السابق / التالي / جولة تلقائية". بكل محطة الزائر يقدر يتلفت شوي (`LIMITS`).
3. نظفوا الضباب اللي يلزق قدام العدسة على طول المسار (خفيف، لأن القطع قريبة من المسار بالممرات الضيقة):
   ```bash
   python scripts/clean_scene.py web/scene.ply --near-cameras data/hall/sparse --near-radius 0.05 --splat
   ```

**عشان المشهد ما يبان طاير بالفضاء** (المسح فيه بس اللي شافته الكاميرا)، بـ `web/scene-config.js`:
- `FLOOR`: أرضية ناعمة تحت المشهد (`center` و `radius`، بنفس اتجاه `cameraUp`).
- `LIMITS`: كم يقدر الزائر يلف (`turnDeg`، رقم أو `[يمين, يسار]`) ويميل (`tiltDeg`) ويقرب/يبعد (`zoomIn`/`zoomOut`) من زاوية البداية، عشان يبقى بالجهة اللي انصورت زين. وضع التحرير بدون حدود.
- الخلفية الدافية والإطار الغامق حوالين الشاشة بـ `#stage` في `index.html`.

بعدها افتحوا `?edit` ولفوا المشهد لين تعجبكم الزاوية، واضغطوا **"خذ الزاوية الحالية كبداية للمشهد"**. إذا المشهد طالع مايل، الاتجاه الصح لفوق (`cameraUp`) ينضبط بـ `web/scene-config.js`.

### 3. السرد والصوت
```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your_key_here          # Windows PowerShell: $env:ANTHROPIC_API_KEY="your_key_here"
python scripts/narrate.py data/scene1/images --place "المتحف الوطني، الرياض"
python scripts/make_audio.py
```
الصوت المحيطي: خذوا `ambient_prompt` من `web/narration.json`، ولدوا منه صوت بأي أداة text-to-audio، واحفظوه في `web/audio/ambient.mp3`.

### 4. تشغيل الموقع محلياً
الصفحة تحتاج سيرفر بسيط (ما تشتغل بفتح الملف مباشرة):
```bash
cd web
python -m http.server 8000
```
افتحوا `http://localhost:8000`. إذا ما فيه `scene.ply`، تقدرون تختارون أي ملف من زر "افتح مشهد".

إذا طلع المشهد مقلوب أو بعيد، عدلوا قيم `CAMERA` في `web/scene-config.js`.

### النقاط التفاعلية (شرح صوتي لكل قطعة)
نقاط مرقمة مثبتة على القطع داخل المشهد. الزائر يضغط على نقطة، والكاميرا تقرب منها، ويشتغل شرح صوتي، والنص يطلع باللوحة.

1. **حطوا النقاط:** افتحوا `http://localhost:8000/?edit`، واضغطوا على أي قطعة بالمشهد عشان تضيفون نقطة. التعديلات تنحفظ بالمتصفح كمسودة.
   - **الشرح التلقائي ✨:** قربوا الكاميرا على القطعة واضغطوا "اكتب الشرح من المشهد". الموديل يشوف صورة القطعة من المشهد، ويكتب شرح سردي بالعربي والإنجليزي. إذا عندكم شرح من المتحف، الصقوه بخانة "شرح من المتحف" أو ارفقوا صورة اللوحة، والموديل ياخذ المعلومات منها بس. الصورة تنحفظ بـ `web/photos/<id>.jpg` عشان الأسئلة تشوف القطعة بعد.
   - أو اكتبوا الشرح بنفسكم. وتقدرون تحفظون زاوية الكاميرا اللي تعجبكم بزر "خذ زاوية الكاميرا الحالية".
2. **نزلوا الملف:** زر "نزّل hotspots.json"، وحطوه في `web/` بدل القديم.
3. **(اختياري) الشرح من اللوحة التعريفية:** صوروا اللوحة اللي جنب القطعة، وخلوا Claude يكتب الشرح منها بس (بدون معلومات من برا):
   ```bash
   python scripts/hotspot_text.py --id h1 --label data/labels/rock.jpg
   ```
4. **الصوت:**
   ```bash
   python scripts/make_audio.py --hotspots
   ```
   يسوي `web/audio/hotspots/h1_ar.mp3` وغيرها بأصوات Microsoft الطبيعية (`edge-tts`، مجاني) ويضيفها للملف. صوت رجالي: `--voice-ar ar-SA-HamedNeural`.
   إذا ما فيه ملف صوت لنقطة، السيرفر يقرأ الشرح بنفس الصوت الطبيعي (`TTS_VOICE_AR` بـ `.env` يغيره)، وإذا ما قدر يرجع لصوت المتصفح.

النقاط مربوطة بملف `scene.ply` اللي انحطت عليه. إذا غيرتوا المشهد (قص أو تدوير بـ SuperSplat)، حطوا النقاط من جديد.

### اسأل عن القطعة (موديل ذكاء اصطناعي يجاوب)
تحت شرح كل نقطة تفاعلية يطلع صندوق "اسأل عن هذي القطعة": الزائر يكتب أو يتكلم 🎙، والموديل يجاوب، والجواب يتقرأ بصوت.

الميزة تحتاج `scripts/server.py` بدل `python -m http.server`، عشان مفتاح API يبقى بالسيرفر وما ينكشف بالصفحة:
```bash
python scripts/server.py
```
والمفتاح يكون بملف `.env` بجذر الريبو (الملف ما ينرفع لـ GitHub). حطوا **واحد** من هذي:

| الموديل | السطر بـ `.env` | ملاحظة |
|---|---|---|
| **OpenRouter** (موديلات مجانية) | `OPENROUTER_API_KEY=...` | المفتاح من https://openrouter.ai/keys. الافتراضي `google/gemma-4-31b-it:free` (يشوف الصور). غيروه بـ `OPENROUTER_MODEL=...`. الموديلات المجانية لها حد يومي |
| **Google Gemini** (مجاني بحدود يومية) | `GEMINI_API_KEY=...` | المفتاح من https://aistudio.google.com/apikey. بالخطة المجانية Google ممكن تستخدم الأسئلة لتحسين خدماتها |
| Claude (مدفوع) | `ANTHROPIC_API_KEY=...` | المفتاح من https://console.anthropic.com |
| **Ollama** على نفس الجهاز (مجاني بالكامل) | `LLM_BASE_URL=http://localhost:11434/v1` و `LLM_MODEL=qwen2.5:7b` | أبطأ، والعربي أضعف. أي سيرفر متوافق مع OpenAI يشتغل بنفس الطريقة |

إذا تغير اسم موديل Gemini، حطوا الاسم الجديد بـ `GEMINI_MODEL=...`.

- الموديل يجاوب من **شرح النقطة + "معلومات إضافية للأسئلة"** اللي تكتبونها بوضع التحرير. ما يخترع تواريخ أو أسماء: إذا المعلومة مو موجودة يقول ما يعرف ويقترح سؤال موظفي المتحف.
- **صورة القطعة (اختياري):** حطوا صورة باسم `web/photos/h1.jpg` (نفس رقم النقطة)، والموديل يقدر يوصف اللي يبان فيها (Gemini و Claude. مع Ollama حطوا `LLM_VISION=1` إذا الموديل يقرأ صور).
- بدون السيرفر (أو على GitHub Pages) الصندوق يختفي وباقي الموقع يشتغل عادي.
- السؤال بالصوت يستخدم خاصية المتصفح (Chrome / Edge / Safari)، والمتصفح يرسل الصوت لخدمته عشان يحوله لنص.

### فيلم الرحلة
افتحوا `http://localhost:8000/film.html` (أو من رابط "سوّ فيلم من صور رحلتك" في الصفحة الرئيسية). الزائر يكتب اسمه، يختار حتى 12 صورة ويكتب سطر عن كل صورة إذا حب، ويطلع له فيلم عمودي (720×1280):
- **البداية:** الكاميرا تلف داخل المشهد 3D مع عنوان "رحلة [الاسم]". إذا ما فيه `scene.ply`، يبدأ بخلفية من أول صورة.
- **الصور:** حركة بطيئة (Ken Burns) وانتقالات ناعمة، والسطر المكتوب يطلع تحت الصورة.
- **الصوت:** `web/audio/ambient.mp3` إذا موجود.
- **الحفظ:** زر "احفظ كفيديو" يسجل الفيلم (mp4 أو webm حسب المتصفح)، وعلى الجوال يطلع زر "شارك".

كل شي يصير داخل المتصفح، والصور ما ترتفع لأي مكان. أثناء الحفظ لازم الصفحة تبقى مفتوحة وظاهرة، لأن المتصفح يوقف الرسم إذا الصفحة بالخلفية.

### 5. النشر برابط (GitHub Pages)
`Settings > Pages > Deploy from a branch`، واختاروا مجلد `/web` أو انقلوا محتواه للـ root. ملفات `.ply` الكبيرة ممكن تتجاوز حدود GitHub (100MB للملف)، فالأفضل تضغطونها بـ SuperSplat أو تحولونها لـ `.ksplat`.
